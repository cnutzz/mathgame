# 🍱 과일 도시락 친구들

받아올림이 있는 한 자리 수 덧셈(예: 7 + 9)을 **10 만들기** 전략으로 연습하는 게임입니다.

도시락에는 자리가 10개 있고, 10칸을 꽉 채워야 도시락 친구가 잠에서 깨어나요.

## 문제 하나의 흐름 (예: 🍎 9개 + 🍋 7개)

1. **어떤 과일을 먼저 넣을까?** 더 많은 쪽(9)을 고르면 빈 도시락에 들어갑니다. 적은 쪽을 고르면 힌트가 나와요.
2. **몇 개 더 넣어야 할까?** 빈자리 수, 즉 9의 보수(1)를 고릅니다. 맞히면 레몬 1개가 들어가고 도시락이 깨어나요.
3. **몇 개 남았을까?** 7을 1과 6으로 가른 결과(6)를 고릅니다.
4. **모두 몇 개일까?** 10 + 6 = 16

화면 위쪽 식에는 가르기(7 → 1, 6) 그림이 단계마다 채워집니다.

- 틀리면 첫 번째에는 힌트가 나오고, 두 번째에는 빈자리나 남은 과일에 숫자를 붙여 함께 세어 줍니다.
- 질문을 누르면 다시 읽어 줍니다(브라우저 한국어 음성). 오른쪽 위 🔊 버튼으로 소리를 끄고 켤 수 있어요.
- 깨운 도시락 친구들은 🍱 버튼에서 모아 볼 수 있습니다. 같은 기기의 브라우저에 저장돼요.

## 단계 고르기

오른쪽 위 단계 버튼(예: `🍱 1단계`)을 눌러 직접 고릅니다. 고른 단계는 기기에 기억돼요.

| 단계 | 이름 | 화면 |
|---|---|---|
| 1 | 🍱 열린 도시락 | 과일과 빈자리가 모두 보여요 |
| 2 | 🎁 뚜껑 닫힌 도시락 | 과일 더미는 숫자 카드로만 보이고 도시락은 뚜껑이 덮여 있어요. 맞히면 뚜껑이 열려요. 막히면 **👀 살짝 보기**(2초)를 쓸 수 있어요 |
| 3 | 🔢 숫자 도시락 | 그림 없이 식과 가르기만으로 풀어요. 두 번 틀리면 점(●)으로 세는 힌트가 나와요 |
| 4 | ⚡ 한 번에! | `9 + 7 = ?`만 보고 바로 답해요. 두 번 틀리면 3단계처럼 차근차근 안내해요. 연속 정답을 세어 줘요 |
| 5 | ⏱️ 1분 타임어택 | 3·2·1 카운트다운 뒤 60초 동안 4단계 문제를 몇 개나 맞히는지 도전해요. 끝나면 최고 기록, 지난 기록, 헷갈렸던 문제(10 만들기 풀이 포함)를 보여줘요 |

단계마다 도시락 친구에게 장식이 붙어요(2단계 🎀, 3단계 ⭐, 4단계 👑, 5단계 ⏱️, 새 기록이면 🏆).

## 스킨

단계 버튼 안에서 스킨도 고를 수 있어요.

- 🍱 **과일 도시락**: 과일을 도시락에 담아요
- 💝 **리본 간식 상자**: 파스텔 색과 리본 장식의 선물 상자에 간식(🧁🍓🍬🍭🍩…)을 담아요

## 실행

`index.html` 파일 하나로 되어 있어요. 브라우저로 열면 바로 플레이할 수 있습니다(태블릿, 휴대폰, PC).
